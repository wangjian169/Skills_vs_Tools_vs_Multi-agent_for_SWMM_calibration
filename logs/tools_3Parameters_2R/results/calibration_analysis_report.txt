1. WORKFLOW OVERVIEW
-------------------
The complete SWMM calibration workflow was executed with the following steps:
1. Base model creation from GIS data using metadata-based lossless restore
2. Parameter selection using Morris sensitivity analysis (balanced intent, top_k=3)
3. Model calibration using ES-ILU with event 1 data
4. Model validation using independent event 2 data
5. Figure generation for performance visualization
6. VLM analysis of generated figures

- GIS Data: data/GIS/ (Manholes.shp, Links.shp, metadata.json)

- Validation Event: data/rainfall/event 2.txt, data/observations/event 2.csv
- Subcatchments: ['1','2','3','4','5','6','7','8']
- Target Node: node_18_total_inflow

3. PARAMETER SELECTION RESULTS
-----------------------------
Method: Morris sensitivity analysis
Intent: balanced
Top_k: 3

Selected Parameters (most influential):
1. imperv (index 2) - mu_star=1.14672
2. zero_imperv (index 7) - mu_star=0.665419
3. slope (index 1) - mu_star=0.562875

These 3 parameters were selected for calibration, reducing the parameter space from 11 to 3 per subcatchment.
